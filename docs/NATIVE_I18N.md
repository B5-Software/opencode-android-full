# 原生界面语言与系统外观

Android 外壳默认跟随系统语言，使用 Android 的有序语言列表和资源回退。当前提供 68 个语言／地区版本，每个版本均包含同一组 513 条原生文案；缺少匹配语言时回退到英语。Android 13 及以上也可通过系统的应用语言设置选择语言，默认仍为跟随系统。

范围包括悬浮导航、布局设置、文件管理、终端工具栏、桌面管理、运行环境、更新、备份恢复、原生通知、系统操作确认和无障碍说明。RTL 交由 Android/Compose 按语言处理。用户文件名、路径、编辑内容、终端输出和外部程序日志原样保留。官方 OpenCode 前端及其语言实现未修改。

主文案来源为 `app/src/main/i18n/catalog.json`，Android XML 和文案索引由 `python tools/native_i18n.py resources` 生成。语言包位于同目录的 `locales/`。英语和简体中文为基础文案，其他语言采用机器初译，并审校参数、品牌名称、路径、文件扩展名等关键内容；繁体中文另有术语调整。尚未逐语言完成母语人工审校，复杂语法和复数表达仍可继续改进。译文随 APK 离线提供，没有引入在线翻译 SDK、运行时翻译请求或新权限。

初译仅在维护工作站上处理固定的通用界面文字，未发送设备数据、用户文件、会话、输入内容或凭据。所有参数保留为占位符。CI 校验语言包完整性、占位符数量、技术名称和路径，并检查 Android 资源是否完整。未完成的语言包不会被生成到 APK 资源中。

Android 12 及以上的原生强调色使用系统动态配色，深浅色跟随系统；较早版本使用应用的兼容配色。平台主题保留正确的 `isLightTheme`，让 WebView 的系统配色媒体查询跟随深浅色。原生 WebView 背景使用同一 Material 配色，没有向网页注入颜色或改写其 CSS。支持主题图标的 Android 13 启动器可使用新的 monochrome 图层。

真机验收：K30 / Android 16，英语、日语、阿拉伯语的可见导航切换、RTL、未知语言回退、有序语言列表、参数中 Unicode 文件路径保持原样均通过；已有深浅色媒体查询、页面保留、透明度持久化与悬浮球四角像素检查也通过。证据见 `.cache/evidence/k30-native-locale-theme.txt`。其余语言尚未逐一完成真机排版与人工语言验收。
