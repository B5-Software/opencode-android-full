# 自适应工作区

悬浮球的“工作区布局”提供开发工作区、OpenCode + 桌面、单页专注。官方 WebUI、后端和桌面仍使用原有实现。

布局依据当前窗口的可用宽高选择，不判断手机或平板型号。宽度至少 840 dp、完整窗口高度至少 320 dp 时可以分屏；窄窗口使用单页。开发布局显示项目文件和当前主页面，Hybrid 同时显示 OpenCode 与桌面。桌面仍须主动启动。

底部终端需要至少 560 dp 的内容高度。右侧终端需要至少 1280 dp 的内容宽度；空间不足时回到底部或收起。Hybrid 文件侧栏需要 1120 dp。被收起的页面可通过悬浮球单独打开。软键盘改变内容高度，但不会切换用于保存布局的窗口分类。

拖动分割线可以改变比例。分割线也支持键盘方向键和无障碍调整。面板右上角可以放大为单页，悬浮球中的“恢复分屏”返回原布局。窗口分为 compact / expanded / large，并分别记录短、高窗口的布局选择；开发和 Hybrid 的面板开关、终端位置及比例独立持久化。数据保存在应用私有 SharedPreferences，不进入项目。

使用固定的面板父节点和页面 key，只改变平面矩形的位置与尺寸。切换分割结构不移动 AndroidView 到另一个子组合，也不重建仍可见的 WebView。切走或收起页面可以释放其视图；PTY 和 Linux 服务由服务层管理。原有页面状态存储、浏览器返回、SAF 文件选择和退出确认保留。

实体键盘快捷键使用 Ctrl + **左 Alt**，右 Alt / AltGr 留给国际文字输入：

| 按键 | 操作 |
| --- | --- |
| 1–5 | OpenCode、终端、桌面、文件、运行环境 |
| B / T | 显示或收起文件 / 终端 |
| M | 开发 / Hybrid 切换 |
| Enter | 单页放大 / 恢复 |
| \ | 布局设置 |

快捷键由 Activity 的公开键盘事件回调分发，WebView 拥有焦点时也可使用。常规 Ctrl、Alt、Shift、鼠标和滚轮继续由各页面处理。文件列表的鼠标右键、触摸长按及“⋮”进入相同的文件操作菜单，右键不会打开编辑器。嵌入式文件栏和终端使用紧凑工具栏。

## 验证范围

`AdaptiveWorkspaceTest` 使用明确标注的合成窗口约束，验证原生 WebView 实例、中文草稿、选择范围、JavaScript 状态、分割线拖动、无障碍调整、窗口比例隔离及损坏值回退。几何检查覆盖大小变化和极端比例，检查面板不重叠、尺寸非负、窗口区域完整。

`HybridWorkspaceAcceptanceTest` 在 K30 的实际横屏窗口运行生产界面，同时连接官方本地 WebUI 和已认证 XFCE。实际 Debian Chromium 本地诊断页验证 GUI；它使用仅限该测试进程的 `--no-sandbox`，不会启用用户兼容模式。标准 Chromium 沙箱的既有失败结论没有改变。测试检查前端 Cookie API=200、实际窗口画面、拖动后的 WebView 身份、单页/分屏及横竖屏恢复，Linux supervisor 身份保持不变。

采集自身 Activity 窗口使用 PixelCopy，并检查画面中的预期颜色区域。反复读取远程 canvas 后再进行 Compose 软件截图曾产生采集异常，因此该路径不能作为最终显示证据。最终窗口图为 `.cache/evidence/k30-hybrid-presentation.png`。

真实平板、折叠铰链、自由窗口管理器、外接显示器及实体蓝牙外设尚需专项验证。合成窗口与 K30 横屏不能替代这些设备验收。
