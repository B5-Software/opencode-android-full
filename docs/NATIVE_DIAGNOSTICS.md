# 原生诊断日志与界面订阅

本模块只处理 Android Host 的运行环境/桌面诊断，保持官方 OpenCode 前端、协议、用户 PTY 输入输出和终端历史原样。

`RuntimeState` 与 `DesktopState` 分别提供 `status` 和 `current`。`status` 不携带日志正文，安装、运行、连接和错误状态同步更新；工作区、桌面容器及维护控件只订阅它。原生日志正文只有日志组件订阅，离开对应页面即释放该订阅。这样后台 stdout 不会通过日志字段通知整个工作区重组。

`DiagnosticLog` 使用整行环形缓冲：运行环境最多 48 × 1024 个 UTF-16 字符，桌面最多 12,000 个字符，均最多 512 行。日志通知合并为每 250 ms 至多一次，只有待发布输出时安排单次任务；没有周期性空转任务或新增 wake lock。状态变化立即包含已有诊断，不等待计时器。快照携带递增版本，较早的异步发布不能覆盖较新的状态快照；发布时不持有日志锁。

进程输出通过 `DiagnosticReader` 分块解码 UTF-8，兼容 CR、LF、CRLF 和结尾无换行。单个输入行超过 4,096 个 UTF-16 字符后，整行丢弃并显示占位，继续排空该行直到换行，避免无限行分配和截断凭据。直接写入的过长异常信息也不保留前缀。原始诊断 PTY smoke 输出使用此读取器，用户交互 PTY 不经过它。

脱敏先清理 ANSI/control 序列，再处理常见认证头、Cookie、JSON/环境/查询参数中的凭据字段、配对路径、URI userinfo、Bearer 和常见密钥形态。遇到 PEM 私钥块时略去内容。当前运行期间，Host 额外登记自动生成的 OpenCode/桌面密码、桌面 VNC 短密码、WebSocket token 和对应 Basic 编码；引用计数租约保留到服务异常处理及清理完成。登记不扫描提供商配置，也不持久化秘密。

这些规则不是任意项目内容或所有编码方式的通用秘密检测器。日志仍可能包含文件名和普通程序输出，应按私有工作数据处理；本模块不新增网络上传或日志导出。`RuntimeSnapshot` 内部连接字段仍供本地 WebView 配对使用，不应整体序列化为公开报告。

验收覆盖突发日志通知、并发完整行、缓存上限、凭据租约、头/字段/URI 脱敏、ANSI/私钥、超长行后的恢复、单字节 UTF-8 读取及长字段扫描。实际设备结果与限制记录在 [验收记录](VALIDATION.md)。通知次数不能替代可见 WebView 滚动/流式交互的帧率测量。
