# 启动工作区恢复

应用保存最近确认的本地 OpenCode 会话 ID 和目录，重新启动服务时先验证目录存在、会话确实属于该目录，再恢复原会话。没有记录时创建并进入 `/workspace/helloworld`；旧版仅留下 `/root` 或 `/`、没有已确认会话 ID 的默认记录也迁移到该目录。旧目录已不可用时回到 helloworld，原目录与数据不会被删除。

官方服务模式可能使用自己的 HOME；应用通过正式会话接口指定项目目录和会话路由，不修改官方服务或前端源码。原生文件管理和新终端跟随所选工作区。切换目录时清除旧目录的会话 ID，避免把会话关联到错误目录。

冷启动 WebView 优先使用已确认的工作区路由，旧 Activity 保存的 `/root` 会话不能覆盖它；恢复历史期间短暂出现的旧路由不会重新写入工作区记录。现有活动页面切换标签时继续保留页面，窗口旋转也不会为了恢复工作区而强制刷新。

持久化内容仅为目录和会话 ID，不包含密码、认证链接、命令或对话正文。更新与加密备份继续保留这些设置。异常终止后的原有明确重启与不重放命令规则继续适用。

K30 的独立真实 Debian/官方 OpenCode 测试验证了首次 helloworld、切换目录后杀死 Android 宿主、显式重启后恢复同一会话；原有源码、编译结果和会话数据保留，终端命令没有重放。该回归耗时 87.599s，证据为 `.cache/evidence/k30-workspace-restore-real.txt`。另有配置损坏、旧默认目录迁移、目录切换和浏览器旧历史恢复检查。
